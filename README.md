# JCF Intelligent Network Manager

Target: **native CentOS Stream 9 / .NET 10**, SQL Server–backed ASP.NET Core Identity, and simulated Aruba inventory. No Docker runtime.

The application source must be verified and published before the installation script can be used. Never expose the insecure `DemoMode` identities to the network or enable device writes without hardware acceptance.

**Do not place passwords, SQL connection strings, certificates or JCF internal network information in this public repository.**
